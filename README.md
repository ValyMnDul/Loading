# Loading

Loading is an incremental idle game that simulates the process of downloading a large amount of data in a controlled environment. The player’s objective is to reach a total of 100 GB downloaded by continuously optimizing the download speed.

The game starts with a very low transfer rate. Progress can be accelerated through direct interaction and by purchasing upgrades that improve connection performance. Each upgrade increases the download speed and interaction efficiency, while its cost scales progressively, encouraging strategic resource management.

## Tech Stack
- Next.js
- Tailwind CSS
- TypeScript
- Vercel for hosting
- VsCode for development
- GitHub for version control
